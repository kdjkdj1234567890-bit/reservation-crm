# 전화·카톡으로 예약 받느라 일 못 하시는 사장님을 위한 온라인 예약 + 고객 관리 시스템

**예약 시스템이 아닙니다. 사장님의 하루를 통째로 편하게 만드는 것입니다.**

혼자 일하고, 혼자 응대하고, 혼자 걱정하는 사장님 — 밤에 정산 걱정 안 하셔도 돼요.
손님은 전화 없이 1분 만에 예약하고, 사장님은 일만 하세요. 나머지는 이 화면이 챙깁니다.
"놓치고 있던 돈을 찾아주는 시스템" 시리즈 1번 작품입니다. (📦 이 패키지는 총 10종 중 1번입니다 — 다른 9개와 연결됩니다)

## 첫 화면: 사장님의 하루를 숫자로 보여드립니다

`/`에 접속하면 먼저 사장님의 어제가 숫자로 펼쳐집니다.

- "하루 평균 전화·카톡 응대 2시간", "카톡 문의 15건", "월 노쇼 3건으로 날린 45만원"
- 어제 하루 타임라인 — 어디서 많이 보던 하루죠?
- 그리고 전환: **"이제는 이렇게 — 마음 편하게"**
- **가치 계산기**: "월 3만원으로 월 ○○만원을 지켜요" + 투자 대비 ○○배 + 솔직 비교표
  (네이버예약 월 5만원 + 전화 응대 알바 월 200만원 = 월 205만원 vs 이 패키지 월 3만원)

## 왜 만들었는가

- **날짜**: 2026-10-12
- **이유**: 사장님들은 짜증을 넘어 감정적으로 지쳐 있습니다. 혼자 일하고, 혼자 응대하고, 혼자 걱정합니다. 기술적 자동화가 아니라, "밤에 정산 걱정 안 해도 되는" 마음의 평안을 주고 싶었습니다.
- **누구를 위해**: 청소·미용실·이사 업체 사장님 — 개발자가 아니라 돈을 쓰는 사장님, 꿈이 있는 사람들을 위해.

우리는 소프트웨어가 아니라 "혼자가 아닌 장사"를 만듭니다.

## 인간에 대한 약속 7가지 (100점의 진짜 의미)

1. **사람을 사람으로** — "유저"가 아니라 꿈이 있는 사람. 모든 문구에서 존중이 느껴지게 씁니다.
2. **정직** — 숫자 부풀리기·효과 과장 금지. 예시 데이터에는 "예시"라고 씁니다. 거짓된 희망은 폭력입니다.
3. **다크패턴 금지** — 가짜 긴급감, 숨겨진 비용, 탈퇴 어렵게 만들기 금지. 떠나고 싶으시면 데이터를 들고 웃으며 나가세요.
4. **따뜻함** — "수고하셨어요"가 기능 100개보다 값집니다.
5. **신뢰** — "이 데이터는 사장님의 것입니다. 우리는 보관만 합니다." 언제든 CSV로 내려받을 수 있습니다.
6. **겸손** — 우리가 영웅이 아닙니다. "시스템 덕분"이 아니라 "사장님 덕분"입니다.
7. **인내** — 조급하게 팔지 않습니다. 결정은 사장님의 속도로.

자문: "이게 내 아버지의 가게라면 자랑스럽게 권할 수 있는가?" — 기술적 완성이 아니라 인간적 완성입니다.

## 어떤 사장님을 위한 것인가 (업종별 특화)

첫 화면에서 업종을 고르면 메뉴·용어·가격대·특화 기능이 통째로 바뀝니다.

- **🧹 청소업체 사장님** — 현장에서 전화 받느라 작업이 끊기는 게 가장 큰 손해. 평수별 가격표(20평 15만원~), 청소 전후 사진 관리로 "이 업체 실력 있네"를 증명하세요.
- **💇 미용실·네일샵 사장님** — 시술 중 전화는 이제 그만. 시술별 소요시간(펌 2시간 30분은 앞뒤 시간까지 자동 확보), 디자이너별 예약 배정, 재방문 주기 알림(염색 6주)까지 챙겨드립니다.
- **🚚 이사·용달 사장님** — 견적 문의 전화에 하루가 다 가시죠? 평수·거리·옵션(사다리차·포장)을 손님이 입력하면 견적이 바로 계산되고, 이사 당일 체크리스트(8가지)가 예약마다 알아서 생깁니다.

## 실행 방법

```bash
bash run.sh
```

브라우저에서 접속:

- **첫 화면(오프닝)**: http://localhost:5004/ — 짜증 모먼트 → 해결책 → 가치 계산기 → 업종 선택
- **손님 화면**: http://localhost:5004/home — 서비스 선택 → 날짜/시간 → 예약 신청
- **사장님 화면**: http://localhost:5004/admin/briefing — ☀️ 오늘 브리핑 (아침에 보는 도파민 대시보드)

종료는 터미널에서 `Ctrl+C`. (Flask 외 설치 불필요, 별도 설정·외부 API·유료 서비스 없음)
**포트 안내**: 기본 5004번. 사용 중이면 5005, 5006… 순으로 자동 전환되며, 실행 시 터미널에 실제 접속 주소가 표시됩니다.

## 핵심 어필 포인트 (사장님께 드리는 말씀)

1. **밤에 정산 걱정 안 하셔도 돼요** — 오늘 예약·이번 주 매출·돌아온 단골이 아침 브리핑 한 화면에. 커피 마시며 보세요.
2. **전화 응대 0건** — 손님이 직접 날짜·시간을 골라 예약 신청. 사장님은 확정 버튼만 누르세요. 핵심 기능은 3클릭 이내:
   - 예약 확정: 사장님 화면 → 예약 달력 → 확정 버튼 (3클릭)
   - 문자 발송: 보내기 버튼 (1클릭)
   - 단골 확인: 고객 명단 → 고객 클릭 (2클릭)
3. **노쇼 걱정은 내려놓으세요** — 전날 리마인드 문자가 미리 준비됩니다. 동네 평균 노쇼율과 비교도 보여드려요.
4. **단골이 알아서 쌓여요** — 방문이 "완료"되면 횟수가 쌓이고 등급(신규→단골→VIP)이 저절로 올라갑니다. 계산 걱정 마세요.
5. **새 손님이 오면 축하해드려요** 🎉 — 새 예약 접수에 컨페티 애니메이션, 사장님 화면엔 새 예약 배지.
6. **월 3만원으로 월 100만원 이상을 지켜요** — 첫 화면 계산기에서 직접 확인. 투자 대비 30배 이상.

## 입소문 나게 하는 장치

- **보이는 성공**: 손님용 예약 페이지에 "이 가게는 단골안심 예약 시스템을 사용합니다" 배지
- **자랑 버튼**: 월간 리포트에서 "단톡방에 공유하기" 원클릭 → "이번 달 ○○만원 더 벌었어요" 이미지 자동 생성 (PNG 다운로드)
- **이웃 자극**: "같은 동네 김○○청소는 이번 달 예약 42건. 사장님은요?" (익명화, 데모용 예시 표기)
- **추천 보상**: "소개한 가게가 가입하면 둘 다 1개월 무료 + 첫 달 매출 1% 리워드" — 설정 화면에서 소개 링크 생성

## 사용 편의성 (60대 사장님 기준)

- 큰 버튼·큰 글씨, 터치하기 편한 크기
- 모바일 375px 기준 먼저 검증 (스크린샷 `10/11/12` 참조)
- 설명서 없이 1분이면 이해되는 구조: 오프닝 → 업종 선택 → 바로 체험
- 로딩 2초 이내 (실측: 첫 화면 0.02초, 관리자 0.19초)
- 잘못 입력해도 친절하게 안내, 오류 화면 노출 없음

- Python Flask + SQLite (파일 DB, 설치 불필요)

- 한국어 UI, 모바일 반응형
- 업종별 프리셋은 `app.py`의 `INDUSTRIES`에서 관리
